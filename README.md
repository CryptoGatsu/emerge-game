# Emerge

**A new world. A life of its own.**

Emerge is a persistent AI civilization simulator. Players own worlds, fund them with the ecosystem token, and let autonomous citizens build families, work, consume, produce, and trade.

## V1 prototype

- 256×256 world model
- Procedural terrain specialization
- AI citizens and families
- Jobs, needs, production, consumption
- Gold treasury and maintenance
- Buildable infrastructure
- World log and live simulation
- Market and bank interfaces
- Deterministic simulation seeds

The current client uses a local simulation while the multiplayer/server-authoritative layer is developed.
